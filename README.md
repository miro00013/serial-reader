# 応募抽選用シリアルナンバー読み取り

## ▶ アプリはこちら → **https://miro00013.github.io/serial-reader/**

（このページはソースコード置き場です。アプリを使うには上のリンクを開いてください。インストール不要・スマホOK）

CD等の応募抽選チケットの写真から、9桁の英数字シリアルナンバーを自動で読み取るツールです。
写真を複数枚まとめてドロップでき、1枚の写真に複数のチケットが写っていてもまとめて検出します。

**すべての処理はブラウザ（お使いの端末）内で完結します。画像やシリアルが外部に送信されることはありません。**

## 使い方

1. チケットの写真をドラッグ＆ドロップ（複数OK、1枚の写真に複数チケットもOK）
2. 自動で検出・読み取りされます
3. 「要確認: ◯文字目」と表示された行は、切り抜き画像と見比べて確認・修正してください
4. 「すべてコピー」または「CSVで保存」でまとめて取り出せます

自動で検出されなかったチケットは「範囲指定で追加」からシリアル部分をドラッグで囲んで読み取れます。

## 読み取りの仕組み

- レイアウト解析で「同じ高さの文字が等間隔に9個並ぶ行」を検出
- 行全体OCRと1文字ずつのOCRを複数方式で実行し、信頼度の重み付き投票で決定
- i/jのドット、g/j/p/q/yの下降、o/0・s/5・z/2の文字高さなど、字形の幾何学的特徴で誤読を補正
- 疑わしい文字は位置付きでフラグ表示

## 画像が外部に送信されていないことを確認する方法

「シリアルを盗んでいるのでは？」という疑問には、次の方法でどなたでも自分で検証できます。

1. **機内モードで使う** — 一度ページを開いた後、機内モード（オフライン）にしても読み取りは正常に動作します。どこにも通信していない何よりの証拠です（Service Workerで全ファイルを端末にキャッシュしています）
2. **通信を監視する** — ブラウザの開発者ツール（F12）→「ネットワーク」タブを開いたまま使うと、外部への通信が一切発生しないことを確認できます
3. **CSPによる技術的遮断** — [index.html](index.html) の先頭に `Content-Security-Policy`（`connect-src 'self'`）を設定しており、仮に送信コードが存在してもブラウザ自体が外部通信を遮断します
4. **ソースコードの確認** — このリポジトリの全コードが動いているものそのものです。外部に送信するコードが存在しないことを誰でも確認できます
